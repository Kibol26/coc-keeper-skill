# 疯狂发作表（BT）

## 实时疯狂（Real-Time Bout of Madness，1D10 回合）

| 1D10 | 症状 |
|---|---|
| 1 | **失忆**：调查员短暂失忆，本回合行动由 KP 控制（每回合 INT 检定，失败继续失忆） |
| 2 | **暴力倾向**：调查员攻击身边最近的人或物 |
| 3 | **自残**：每回合 1 点伤害（不致死），KP 控制行动 |
| 4 | **偏执狂**：调查员相信所有人都在密谋害他，拒绝配合 |
| 5 | **自大**：调查员认为自己是神选之人，行为开始不可预测 |
| 6 | **恐音症**：对当前环境中的某种声音过度敏感（KP 选），每听到 1 次新声音 → 1/1D4 SAN |
| 7 | **幽闭恐惧**：若在封闭空间，每回合 CON 检定，失败则疯狂寻找出口 |
| 8 | **恐尖症**：若身边有尖锐物（刀、钉子），CON 检定决定是否远离 |
| 9 | **抑郁**：调查员停止活动，蹲坐或哭泣 |
| 10 | **狂躁**：调查员开始大笑、跳舞、唱歌、无法控制地笑 |

## 总结疯狂（Summary Bout of Madness，1D10 小时）

| 1D10 | 症状 |
|---|---|
| 1 | **失忆**：调查员醒来发现自己在一个陌生的地方，不知道怎么来的 |
| 2 | **被劫持**：调查员相信自己被外星人/邪神绑架过，身上有奇怪痕迹 |
| 3 | **暴力**：调查员袭击一个陌生人，记不清原因 |
| 4 | **信念**：调查员坚信某个荒谬的事（如地球是平的） |
| 5 | **重要的人**：调查员认错一个人，把他当成自己的挚友/亲人 |
| 6 | **恐音症**：从现在起，某种声音（铃声、钟声、孩子哭声）触发 SAN 检定 |
| 7 | **恐人症**：从现在起，与特定类型的人（男性/女性/老人/小孩）交流时恐惧检定 |
| 8 | **恐物症**：从现在起，某种物品（蜘蛛、镜子、特定的字）触发恐惧 |
| 9 | **躁狂症**：从现在起，某种行为（偷窃、囤积、说谎、洗手）成为强迫 |
| 10 | **妄想症**：从现在起，调查员认为某个地方（家、工作场所）被监视 |

## 永久疯狂（Indefinite Insanity）

SAN = 0 或累计损失 1/5 触发"持续时间 = 不定"的 BT。

KP 选一个**永久**症状：
- 永久失忆：永远忘记过去
- 永久信念：永远相信某事
- 永久恐惧症：永远对某物恐惧
- 永久躁狂症：永远有某种强迫行为
- 永久暴力倾向：永远可能攻击他人
- 永久妄想：永远被监视/被跟踪

**治疗**：需 Psychoanalysis 检定连续 6 个月每周成功才可恢复。

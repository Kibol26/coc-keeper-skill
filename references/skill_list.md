**建卡流程**（γ 模式）：
1. 玩家选职业
2. 玩家掷属性
3. **职业点 = EDU × 系数**（如教授 4×EDU = 240 点）
4. **兴趣点 = INT × 2**（所有职业通用）
5. 玩家自由分配：母语已 = EDU；闪避 = DEX/2；其他自选
6. 每项技能可点到 0-80%（创建时）

## 常用职业快速模板

### 教授 / 学者
- 强项：图书馆使用、神秘学、Cthulhu Mythos、母语
- 弱项：斗殴、火器、闪避
- 适合：调查型/知识型模组

### 私家侦探
- 强项：侦查、聆听、说服、心理学、潜行
- 弱项：医学、科学
- 适合：任何现代 / 1920s 模组

### 医生
- 强项：医学、急救、心理学
- 弱项：火器、神秘学
- 适合：长期团，队友受伤救回来

### 牧师
- 强项：神秘学、说服、历史
- 弱项：斗殴、攀爬
- 适合：宗教/邪教主题

### 退伍军人
- 强项：火器、斗殴、潜行、追踪、急救
- 弱项：神秘学、艺术类
- 适合：动作向 / 战斗向

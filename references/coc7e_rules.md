# COC 7e 规则速查（房规 3）

> **本 skill 固定使用房规 3**。其他房规不在本速查范围内。

## 一、检定等级

| 骰出 | 等级 |
|---|---|
| 01-05（无视技能值）| **大成功** |
| ≤ 技能值/5 且 > 5 | 极难成功 |
| ≤ 技能值/2 且 > 技能值/5 | 困难成功 |
| ≤ 技能值 且 > 技能值/2 | 一般成功 |
| > 技能值 且 < 96 | 失败 |
| 96-100（无视技能值）| **大失败** |

**注意**：房规 3 的大成功/大失败**不看技能值**。一个技能 90% 的大教授也可能在 01-05 区间大成功，技能 5% 的新手也可能在 96-100 大失败。

## 二、奖励骰 / 惩罚骰

- **奖励骰**：额外投一个十位骰（投 3 个 d10：1 个个位 + 2 个十位），取**最小**的十位
- **惩罚骰**：同上，取**最大**的十位
- 多奖励多惩罚可叠加，但**最小**和**最大**的十位互相抵消

**常见触发**：
- 奖励：熟悉环境、有利装备、助手、专注
- 惩罚：不熟悉、反光、噪音、受伤、黑暗

## 五、技能（60+ 项）

完整列表见 `skill_list.md`。每项技能有基础值，**职业**给固定点数，**兴趣**给额外点数。基础值见下：

- 默认：5（个别为 0、1、10、15、20、25、50、80）
- 信用评级 (Credit Rating)：0
- 母语 (Own Language)：EDU
- Cthulhu Mythos：0
- 闪避 (Dodge)：DEX/2

**最大技能值**：创建时不超过 80%，游戏内可通过使用成长。

## 六、战斗

### 顺序
1. 按 DEX 排序
2. DEX 同则比较 LUCK
3. 每回合一个动作

### 攻击
- 选武器 → 攻击检定 vs 目标闪避/反击
- 极难成功：伤害骰取最大
- 大成功：伤害骰取最大 × 2（不含体格加值，部分房规含，**房规 3 不含**）

### 伤害等级
- 普通伤：HP 损失
- 重伤：单次伤害 ≥ HP/2（标签"重伤" + 倒地 + CON 检定昏迷）
- 死亡：单次伤害 > HP（当场）
- 濒死：HP=0 且带"重伤"标签

### 闪避 / 反击
- 闪避：放弃本回合攻击，获得 1/2 DEX 作为闪避技能
- 反击：本回合用同一战斗技能对抗攻击
- **对抗结果**：高者胜，平手攻击者胜，双方都失败则都无伤

### 战斗轮
- 双方都声明动作 → 同时投骰 → 比较
- 战斗轮走完一个回合

## 七、理智（SAN）

### SAN check 触发
- 看到超自然物
- 目睹暴力/死亡
- 任何 `san_loss` 在技能表上标注的事件

### 公式
每个事件有"X/Y"两个数字：
- 投骰 ≤ 当前 SAN：扣 X（最少）
- 投骰 > 当前 SAN：扣 Y
- 96-100 大失败：直接扣 Y（房规 3 大失败不看技能值，但仍是大失败）

### 疯狂触发
- **单次损失 ≥ 5 SAN**：1D10 判定进入**实时疯狂**（1D10 回合）或**总结疯狂**（1D10 小时）
  - INT 检定成功：进入疯狂
  - INT 检定失败：压仰记忆，不进入疯狂
- **累计损失 ≥ 1/5 当前 SAN**：同上
- **SAN = 0**：永久疯狂

### BT（疯狂发作）抽取
- 见 `madness_tables.md`
- 实时疯狂：1D10 回合
- 总结疯狂：1D10 小时
- INT 检定：成功 5 回合/小时，失败 1 回合/小时

### 恐惧症 / 躁狂症
- BT 抽到"总结"型 → KP 选一个恐惧症或躁狂症
- BT 抽到"疯狂"型 → 已选过的不重复

### SAN 恢复
- 接触克苏鲁要素 **不** 恢复
- 自我心理调整：在 1D4 周内若 SAN 提升 ≥ 5，INT 检定 1 次决定是否完全恢复
- 精神分析：6 个月内每周一次 Psychoanalysis 检定，成功恢复 1D3
- 休息：1 周后 INT 检定，成功恢复 1D3 SAN

## 八、幸运（LUCK）

- 检定失败时可消耗 LUCK 抵消（1 点 LUCK = 重新投一次，取好结果）
- LUCK 创建时 3D6×5，游戏内成长 +1D3 一次性
- 不能主动"花" LUCK 成功 — 只能用在"差点成功"时挽救

## 九、Push Roll（孤注一掷）

- 检定失败（**非大失败**）后可申请
- KP 必须**先揭示失败后果**（"如果你再失败，灯会爆炸"）
- 玩家同意后重投，**必须**接受新结果
- 仅非战斗技能可用

## 十、技能成长

- 技能使用过且 D100 > 当前技能值
- 团结束后 +1D3%
- 取小（即不能超过新掷出值）
